# Frame-Relay documentation

Frame-Relay turns your Figma components into a design kit your AI coding agent follows.

New here? Start with [Getting started](./getting-started.md). It walks you from an empty folder to
an AI-built page. If you want the ideas first, read [Concepts](./concepts.md).
