# Development docs

This folder holds working documents for the people and agents building Frame-Relay. It is not
user-facing documentation; the user-facing docs live in `docs/` (see `docs/README.md`).

- **Phase plans** describe the scope, design decisions and exit criteria for an upcoming phase.
  Name them `phase-N-<topic>.md` so they sort chronologically.
- **Progress logs** record what actually landed, what was skipped and any follow-ups for a phase.
  Keep one log per phase and append entries instead of rewriting history.

Anything in here may go stale once a phase merges; the merged behavior is documented in `docs/`.
